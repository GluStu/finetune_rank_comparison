## What Changed

Run 001 established the initial comparison between an unfine-tuned
baseline, full fine-tuning, and LoRA configurations with different
adapter ranks. The code was subsequently organized into `data.py`,
`train.py`, and `evaluate.py` to separate data preparation, training,
and evaluation.

## Findings

The recorded baseline validation perplexity was 76.48, while full
fine-tuning achieved 41.66. Among the tested LoRA configurations,
rank 4 achieved the lowest recorded perplexity at 61.24.

LoRA rank 4 used 73,728 trainable parameters, compared with
approximately 81.9 million for full fine-tuning. Increasing the rank
did not consistently improve validation perplexity.

These results are preliminary because each configuration was run
only once. Run 002 addresses this limitation by repeating the
experiments across multiple seeds.

## Limitations

Training time was not consistently recorded in run 001. The small
training subset and limited number of optimization steps also limit
the generalizability of the results.
