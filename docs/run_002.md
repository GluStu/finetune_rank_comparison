# Run 002: Multi-Seed LoRA Rank Comparison

## Configuration

- Model: DistilGPT-2 (`distilgpt2`)
- Dataset: WikiText-2 (`wikitext-2-raw-v1`)
- Training subset: 1,000 examples per seed
- Validation subset: 200 examples
- Training budget: 100 steps per trained configuration
- Batch size: 4
- Seeds: 42, 43, 44
- Configurations: baseline, full fine-tuning, LoRA ranks
  1, 2, 4, 8, 16, 32, 64, 128
- LoRA alpha: 16
- LoRA dropout: 0.1
- LoRA target module: `c_attn`
- LoRA learning rate: 2e-4
- Full fine-tuning learning rate: 5e-5

## Hardware
Operating system: Ubuntu 24.04.1 LTS
CPU: AMD Ryzen 5 5600H
GPU and VRAM: CPU-only
Python and PyTorch versions: 3.13.3

## What Changed

Run 002 extends run 001 by repeating every configuration across
three seeds. The sweep script reuses the shared data-loading and
evaluation modules.

The script records configuration, rank, seed, trainable parameter
count, training time in seconds, and validation perplexity in
`experiments/run_002/results.csv`. Results are saved after every
completed run to reduce the risk of losing progress.

## Findings

Across three random seeds (42, 43, and 44), the baseline validation perplexity was 76.48, while full fine-tuning achieved a mean of 41.55 (SD = 0.23). LoRA configurations achieved mean validation perplexities between 61.15 and 61.82, with rank 4 performing best on average (61.15, SD = 0.46). Although all LoRA configurations substantially improved on the baseline, none matched full fine-tuning.

LoRA required less training time, averaging approximately 9.4–9.8 seconds per run, compared with 14.45 seconds (SD = 0.11) for full fine-tuning. Rank 4 used only 73,728 trainable parameters, approximately 99.91% fewer than the 81.9 million parameters required for full fine-tuning.

The ranking observed in run 001 was broadly consistent across seeds: rank 4 achieved the lowest mean validation perplexity. However, the best-performing rank varied between individual seeds, and increasing the rank did not consistently improve performance. Training times and validation perplexities were generally stable across runs, although rank 2 showed greater variability in validation perplexity (SD = 0.78).

Overall, the results indicate that full fine-tuning provides the best predictive performance, while LoRA offers a substantial reduction in trainable parameters and training time. Rank 4 provides the best average validation performance among the tested LoRA configurations. These conclusions remain preliminary because the evaluation includes only three random seeds.


## Limitations

The sweep uses a small training subset, a fixed training budget,
and three seeds. Results may depend on the selected hyperparameters,
dataset subset, software versions, and hardware.
